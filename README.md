# ao_ma

Helper scripts for reading, preparing and converting movie files.

## Modules

- `pre_upscale_phase/` — DVD prep, subtitle OCR and remux before upscaling (on branch `feat/pre_upscale_phase`).
- `luyen_co/` — lọc frame của một người trong ảnh/video CCTV theo ảnh tham chiếu, chọn góc/pose đa dạng (on branch `feat/luyen_co`).
